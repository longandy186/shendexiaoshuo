# AI 创作助手 - 提示词与工作流程详解

> 本文档详细展示 AI 创作助手的各个功能、提示词设计以及 AI 工作的每一步动作。

---

## 📋 功能概览

AI 创作助手提供以下 5 个核心功能：

1. **智能续写** - 根据已有内容智能续写故事
2. **生成章节** - 根据大纲生成章节内容
3. **全文润色** - 优化语言表达和风格
4. **生成大纲** - 生成小说章节大纲
5. **剧情建议** - 提供剧情发展建议

---

## 🎨 语言风格提示词库

AI 创作助手提供 5 种语言风格模板，用户可以选择：

1. **战斗场景** - 战斗场景专用，适合玄幻、仙侠等题材
   - 关键词：战斗、爽点、动作、技能
   - 特点：快节奏、动作描写突出、强调视觉冲击力

2. **对话技巧** - 注重人物性格刻画
   - 关键词：对话、人物、性格、关系
   - 特点：人物说话方式独特、对话推动情节、言外之意

3. **环境描写** - 突出氛围营造，调动五感
   - 关键词：环境、描写、氛围、五感
   - 特点：五感描写、氛围烘托、细节刻画

4. **人物出场** - 注重第一印象，立人设
   - 关键词：人物、出场、立人设、印象
   - 特点：外貌鲜明、体现性格、场景烘托

5. **情感爆发** - 注重情感共鸣，冲击力强
   - 关键词：情感、爆发、抉择、共鸣
   - 特点：情感铺垫、情感爆发、内心独白、共鸣设计

**使用方式**：
- 在 AI 助手面板中，点击"语言风格"下拉框
- 选择合适的风格模板
- 点击"推荐风格"按钮，系统会根据生成类型推荐最适合的风格
- 选中后，AI 将按照该风格生成内容

**智能推荐**：
- 智能续写 → 推荐战斗场景、情感爆发
- 生成章节 → 推荐环境描写、人物出场
- 全文润色 → 推荐对话技巧、环境描写
- 剧情建议 → 推荐情感爆发、对话技巧

## 🔄 AI 工作流程

### 步骤 1：接收请求

```typescript
// API 端点：POST /api/v1/ai/generate

请求参数：
{
  type: 'continue' | 'chapter' | 'polish' | 'outline' | 'plot',
  model: 'doubao' | 'qwen' | 'kimi',
  prompt: '用户输入的提示词',
  context: {
    novelId: '小说ID',
    chapterId: '章节ID',
    chapterTitle: '章节标题',
    chapterKeywords: '章节关键词',
    previousContent: '前文内容',
    characters: [...],     // 角色设定
    worldSettings: [...],  // 世界观设定
    genre: '小说类型',
    chapterCount: 章节数量
  }
}
```

### 步骤 2：模型映射

```typescript
模型映射配置：
- doubao (豆包) → doubao-seed-1-8-251228  (多模态 Agent 优化模型)
- qwen (千问)   → glm-4-7-251222            (通用模型)
- kimi (Kimi)   → kimi-k2-5-260127          (最智能模型)
```

### 步骤 3：从数据库读取设定（最高优先级）

```typescript
// 如果提供了 novelId，从数据库读取角色和世界观设定
// 数据库中的设定具有最高优先级，覆盖前端传递的设定

数据库读取逻辑：
1. 调用 dbGetNovelSettingsForAI(novelId)
2. 提取 worldSettings（世界观设定）
3. 提取 characters（角色设定）
4. 替换 enhancedContext 中的设定
```

**为什么数据库优先？**
- 数据库设定是用户明确保存的，具有权威性
- 前端 localStorage 可能有过期数据
- 确保 AI 创作时使用最新的设定

        const text = chunk.content.toString();
        const data = `data: ${JSON.stringify({ content: text })}\n\n`;
