# 数据诊断与修复工具使用指南

## 功能说明

本工具用于诊断和修复"神的小说工坊"的数据存储问题，帮助您解决以下常见问题：

1. **用户数据无法保存** - 登录后用户信息丢失
2. **小说数据无法保存** - 创建小说后数据不显示
3. **角色/章节数据丢失** - 添加的角色或章节消失
4. **localStorage 错误** - 浏览器提示存储空间不足或访问被拒

## 使用方法

### 1. 访问诊断页面

在首页点击"系统诊断"按钮，或直接访问 `/diagnostic` 路径。

### 2. 运行检测

点击"开始检测"按钮，系统会自动检查以下项目：

- **localStorage 基本功能** - 验证浏览器是否支持 localStorage
- **用户数据** - 检查登录状态和用户数据完整性
- **小说数据读取** - 检查能否正常读取小说列表
- **小说数据保存** - 测试创建和保存新小说的功能
- **数据完整性** - 验证所有数据格式的正确性
- **存储空间** - 显示当前存储使用情况

### 3. 查看检测结果

检测完成后，会显示每个测试项的结果：

- ✅ **绿色** - 测试通过，功能正常
- ❌ **红色** - 测试失败，存在问题
- 📊 **详情** - 点击可查看详细错误信息

### 4. 自动修复

如果检测到问题，可以点击"自动修复"按钮：

- 系统会自动尝试修复检测到的所有问题
- 修复完成后会显示修复报告
- 修复完成后建议重新运行检测验证

### 5. 数据备份与恢复

#### 导出数据

点击"导出数据"按钮，将所有数据导出为 JSON 文件：

- 包含用户信息、所有小说、角色、章节等数据
- 建议定期备份，防止数据丢失
- 文件命名格式：`ai-novel-backup-YYYY-MM-DD.json`

#### 导入数据

点击"导入数据"按钮，选择之前导出的 JSON 文件：

- 会覆盖当前所有数据
- 导入前建议先导出当前数据作为备份
- 导入成功后会自动刷新页面

### 6. 清空所有数据（危险操作）

⚠️ **警告：此操作不可逆！**

点击"清空所有数据"按钮会删除所有数据：

- 删除登录信息
- 删除所有小说、角色、章节
- 删除所有备份和元数据

**仅用于以下情况：**
- 数据损坏严重，无法修复
- 准备重置应用
- 测试功能

## 常见问题与解决方案

### 问题 1：localStorage 不可用

**症状：**
- 检测结果显示"localStorage 读写失败"
- 浏览器控制台显示相关错误

**可能原因：**
1. 浏览器禁用了 cookies 和网站数据
2. 使用了隐私/无痕模式
3. 浏览器存储空间已满
4. 第三方 Cookie 被阻止

**解决方案：**
1. **检查浏览器设置**
   - Chrome: 设置 → 隐私和安全 → Cookie 和其他网站数据
   - Firefox: 选项 → 隐私与安全 → Cookie 和网站数据
   - 确保允许存储 cookies 和网站数据

2. **退出隐私模式**
   - 使用正常模式访问应用

3. **清理存储空间**
   - 删除不需要的网站数据
   - 清理浏览器缓存

4. **允许第三方 Cookie（如果是 iframe 嵌入）**
   - 检查是否在 iframe 中运行
   - 允许第三方 Cookie

### 问题 2：用户数据缺失

**症状：**
- 检测结果显示"未找到登录用户"
- 频繁被重定向到登录页面

**解决方案：**
1. 重新登录
2. 点击"自动修复"尝试修复
3. 如果仍无法解决，清空所有数据后重新开始

### 问题 3：小说数据损坏

**症状：**
- 小说列表显示错误
- 无法打开小说详情
- 检测结果显示"小说数据格式错误"

**解决方案：**
1. **点击"自动修复"**
   - 系统会自动备份损坏数据
   - 尝试修复数据格式

2. **手动恢复备份**
   - 如果有备份文件，使用"导入数据"恢复

3. **部分恢复**
   - 数据会尝试保留可读部分
   - 丢失的部分需要重新创建

### 问题 4：存储空间不足

**症状：**
- 保存数据时提示存储空间不足
- 旧数据丢失

**解决方案：**
1. **导出数据**
   - 导出所有数据到本地文件

2. **清空浏览器存储**
   - 删除不需要的网站数据
   - 清理浏览器缓存

3. **重新导入**
   - 重新导入需要的数据

### 问题 5：数据一致性问题

**症状：**
- 角色数量与实际不符
- 章节内容错乱
- 世界设定丢失

**解决方案：**
1. **点击"自动修复"**
   - 系统会自动检查并修复数据一致性
   - 自动清理无效引用

2. **手动验证**
   - 检查所有小说数据
   - 确认角色、章节完整性

## 技术细节

### 数据存储结构

所有数据存储在浏览器的 localStorage 中，键名前缀为 `ai_novel_`：

- `ai_novel_user` - 用户信息
- `ai_novels` - 小说列表
- `ai_novels_backups` - 自动备份
- `ai_novels_metadata` - 元数据

### 数据备份机制

系统会自动创建备份：

- 每次保存数据时自动备份
- 保留最近 7 天的备份
- 修复数据前自动备份

### 数据完整性检查

系统会验证：

- 所有必要字段存在
- 数据类型正确
- 数组格式有效
- 引用关系一致

## 最佳实践

1. **定期备份数据**
   - 每周导出一次数据
   - 重要更新前先备份

2. **及时处理问题**
   - 发现数据异常立即诊断
   - 不要等到数据丢失再修复

3. **保持浏览器更新**
   - 使用最新版本的浏览器
   - 确保浏览器功能正常

4. **注意存储限制**
   - localStorage 通常限制为 5-10MB
   - 定期清理不需要的数据

## 获取帮助

如果以上方案无法解决您的问题：

1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签的错误信息
3. 查看 Application 标签的 Local Storage 内容
4. 将错误信息和截图提供给技术支持
